# Student OS

> A modern productivity platform for students — routines, study planning, habits, and focus tools in one place.

⚠️ **This project is currently in active development.**  
Features, architecture, database schema, and UI may change frequently.

---

## Overview

Student OS is a web application designed to help students organize their academic life through:

- 📅 Weekly routines
- ✅ Task and study management
- 🎯 Habit tracking
- ⏱️ Pomodoro / focus tools
- 📚 Study planning
- 📄 Document organization

The goal is to create a fast, clean, and practical system focused on productivity and usability.

## Running Locally

### Clone the repository

```bash
git clone https://github.com/juanoliveira90/student_os.git
cd student_os
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```
